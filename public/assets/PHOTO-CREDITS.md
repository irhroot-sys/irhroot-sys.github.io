# AALKC photography sources

The photographs below are used as licensed, representative industrial imagery. They do not depict AALKC facilities unless explicitly stated.

- `service-industrial-dismantling.webp` — Yasin Hemmati, [Unsplash](https://unsplash.com/photos/lp6CBQSr1Ek), used under the Unsplash License. Also used as the homepage hero image.
- Heavy Logistics service image — Tahir mq, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Jeddah_Islamic_Port_1.jpg), used under CC BY-SA 4.0. Jeddah Islamic Port, Jeddah, Saudi Arabia, photographed 2019. Cropped/resized from the original; no other alterations. Replaces a prior placeholder image that depicted an American desert highway and was not representative of the Kingdom. **This image is embedded directly in `src/data/siteContent.jsx` as a base64 data URI** rather than as a separate file in this folder — the tooling available for this change could not reliably write new binary files into `public/assets/` (content was silently corrupted/truncated on every attempt), so inlining it as a data URI was the only reliable way to ship a real, correctly-licensed replacement photo. Functionally this is identical to a normal image reference; it just lives in the JS bundle instead of a standalone `.webp` file.
- `service-container-handling.webp` — Willians Huerta, [Pexels](https://www.pexels.com/photo/36397860/), used under the Pexels License.
- `service-metal-sorting.webp` — Willians Huerta, [Pexels](https://www.pexels.com/photo/36397854/), used under the Pexels License.
- `service-global-trade.webp` — Willians Huerta, [Pexels](https://www.pexels.com/photo/36397819/), used under the Pexels License.
- `service-scrap-metal.webp` — source and license undocumented. Used on the Scrap Purchasing service card and on four material cards (copper, heavy melt steel, aluminum, brass). A reverse-image and photographer-portfolio search did not surface an exact match on Pexels, Unsplash, or Wikimedia Commons; the image shows no signs of AI generation and no geographic markers that would make it inappropriate, but its license could not be positively confirmed. Recommend AALKC confirm the original purchase/download record, or commission a replacement, before this file is relied on for commercial use at scale.
- `service-construction-materials.webp` — source and license undocumented. Used on the Materials page hero and on three material cards (rebar, stainless steel, plate/structural). Same status and recommendation as above.

## Known repository artifacts that could not be cleaned up

- `hero-dammam-scrap-yard-v2.webp` was an AI-generated image (created with OpenAI ImageGen) previously used as the homepage hero. It was replaced everywhere in the site's code with the real, licensed photograph noted above (`service-industrial-dismantling.webp`) — no page references this file. It still physically exists in the repository with its original AI-generated content, because no available tool can delete a file or reliably overwrite binary file content in this repository. Delete it directly with `git rm public/assets/hero-dammam-scrap-yard-v2.webp` when you have normal git access.
- `service-heavy-logistics.webp` is likewise unreferenced by any page (the real replacement photo is inlined as a data URI — see above). An earlier attempt to overwrite this file with real binary image data was silently corrupted by the available tooling, so it currently contains garbled placeholder text, not a valid image. It is harmless (nothing loads it) but should be deleted with `git rm public/assets/service-heavy-logistics.webp` when you have normal git access.
