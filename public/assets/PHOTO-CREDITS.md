## Note on the heavy logistics image

The Jeddah Islamic Port photo above is stored as an inline base64 data URI in `src/data/siteContent.jsx` rather than as a standalone `.webp` file in this folder. Every attempt in this environment to write new binary image bytes directly into a repository file (via either of the two available GitHub file-write tools) resulted in the raw base64 text being stored as the file's literal content instead of being decoded — i.e. binary file writes are not currently possible through this tooling, only text file writes. The data-URI approach avoids this entirely since it's plain text, and was verified byte-for-byte correct against the source image. Two now-unreferenced files that were casualties of this limitation (`hero-dammam-scrap-yard-v2.webp`, an old AI-generated hero image, and a corrupted `service-heavy-logistics.webp`) have since been deleted from the repository.
